## Documentation Standards

When adding new documentation:

1. Place files in the `docs/` directory
2. Use descriptive, UPPERCASE filenames for guides
3. Use lowercase with hyphens for technical docs
4. Update this README with the new documentation
5. Include a brief description of what the document covers
6. Use proper markdown formatting

## Document Categories

- **Guides** - Step-by-step implementation guides
- **APIs** - API documentation and usage
- **Reports** - Analysis and status reports
- **Optimization** - Performance and best practices
- **Maintenance** - Backup, cleanup, and maintenance procedures
